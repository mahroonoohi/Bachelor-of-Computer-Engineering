# Cinema Management System

A **C++** and **Qt** based cinema management system that allows administrators and users to manage, view, search, and group movies, as well as register, log in, and reserve tickets.

---

## Features

### Movie Management (Admin)
- Add new movies
- Remove movies
- Edit movie information
- Display all movies
- Group movies
- Search movies by:
  - Movie name
  - Director
  - Actors
  - Country of production
  - Genre
  - Production year
  - Movie duration

### User Features
- Register and log in
- View movie list
- Search for movies
- View movies by groups
- Reserve tickets
- Countdown timer for certain actions
