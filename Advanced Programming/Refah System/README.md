# Refah System – Personnel Management

![C++](https://img.shields.io/badge/Language-C++-blue)

## Overview
Refah System is a **C++ console application** for managing personnel information, including **Bosses**, **Supervisors**, and **Employees**.  
It allows you to **add, edit, delete, display personnel**, and calculate their **income** based on working hours, rewards, and other parameters.

---

## Features
- Add new personnel:
  - Boss
  - Supervisor
  - Employee
- Edit existing personnel information
- Delete personnel by their national ID (**Melli code**)
- Display personnel information
- Calculate income for personnel
- Console output with **colored text**
- Log data to `fileout.txt`
