### **Internet Engineering** (Internet_Engineering)  
*November – December 2023*  
**Course Project – Network and Server Setup**  
*Supervisor: Dr. Tork Ladani*

#### 🧠 Overview
This project focused on the **setup, configuration, and management of network services and servers** in a controlled lab environment.  
The goal was to understand **server administration**, **network protocols**, and **service deployment**, providing hands-on experience with **real-world networking scenarios**.

---

#### ⚙️ Core Tasks
- Configured and installed **essential network services**:
  - **DHCP Server**: Automated IP address allocation within the network.
  - **Web Server**: Hosted internal web pages and services for team use.
  - **Mail Server**: Full setup for email communication within the lab environment.
- Mail Server setup details:
  - Domain configured as **UITELOC**.
  - Created at least **one active admin email** and **one for each team member**.
  - Configured **POP3 and IMAP protocols** for email access.
  - Verified connectivity through standard email clients such as **Outlook**.
- Ensured **proper network configuration**, including DNS resolution and routing for internal communication.

---

#### 🧩 Skills and Knowledge Gained
- Understanding of **IP addressing, subnets, and DHCP**.
- Hands-on experience with **email server administration** (user management, protocols, security).
- Practical knowledge of **web server hosting** and service deployment.
- Familiarity with **network troubleshooting and client-server communication**.
- Basic exposure to **Linux server commands** and **configuration files** for service setup.
