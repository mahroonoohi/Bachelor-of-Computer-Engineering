### **Internet of Things (IoT) Programming**   
*May – June 2024*  
**Final Project – IoT Systems Development**  
*Supervisor: Dr. Bohlooli*

#### 🧠 Overview
This project focused on the **design and implementation of an IoT system** enabling **remote control and monitoring** of devices through both **local network** and **internet-based solutions**.  
The main objective was to gain practical experience in **embedded programming**, **network communication**, and **IoT integration** using Arduino and Telegram APIs.

---

#### ⚙️ Core Tasks
- Implemented an **IoT system for remote LED control**:
  - Controlled LEDs via **Wi-Fi** and **local network** connections.
- Developed **Arduino-based client code**:
  - Handled **HTTP requests and responses**.
  - Ensured proper communication with the server and accurate status reporting.
- Created a **Telegram bot server**:
  - Enabled users to **send commands remotely**.
  - Monitored **LED status** in real-time.
- Tested and debugged the system for **reliable operation** over different network scenarios.

---

#### 🧩 Skills and Knowledge Gained
- Embedded programming with **Arduino** and **microcontroller integration**.
- Experience with **HTTP protocols** for IoT communication.
- Development of **Telegram bots** for remote interaction.
- Network troubleshooting for **local and internet-based device control**.
- Practical knowledge of **IoT system design, testing, and deployment**.
