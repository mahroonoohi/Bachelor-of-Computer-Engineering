## Project Description
This project is a **Video Player Application** developed using **Android Studio** and **Kotlin**. The application allows users to play videos with basic controls and supports online streaming.

## Features
- Play, pause, seek, and full-screen video playback.
- Integration with **ExoPlayer** for smooth media rendering and adaptive streaming.
- Playback of online videos, including **YouTube content**.
